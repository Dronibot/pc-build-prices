# Ціни на комплектуючі ПК

Сайт (GitHub Pages), що стежить за цінами на деталі двох збірок ПК:

- **Моя збірка** — деталі й посилання з таблиці (оригінальні магазини німецькі, ціни в €);
- **Оновлена збірка** — пропозиція з деталями, які легко купити в Україні.

Для кожної деталі показано поточну ціну, коли вона змінилася, історію змін і еквівалент у гривнях.

## Як це працює

- **Робот оновлює ціни кожні 2 години** (GitHub Actions, `.github/workflows/update.yml`): запускає `scripts/update.mjs`, і якщо щось змінилося — комітить `data/prices.json` та `data/history.json`. Сайт читає ці файли, сервер не потрібен.
- **Магазини з доставкою в Німеччину** — з [Geizhals.de](https://geizhals.de/): усі пропозиції (магазин, ціна, доставка) і схожі моделі для заміни; плюс оригінальні посилання з таблиці, якщо магазин віддає сторінку. Geizhals оновлюється з домашнього ПК (див. «Магазини»).
- **Курс** — офіційний курс НБУ (EUR, USD) на день оновлення.
- Якщо магазин недоступний, на сайті видно помилку й останню відому ціну.

Файли даних:

| Файл | Що в ньому |
|---|---|
| `data/config.json` | збірки, деталі, посилання (редагується вручну) |
| `data/overrides.json` | заміни деталей, зроблені через issue |
| `data/prices.json` | останні ціни, курс, кандидати для заміни (пише робот) |
| `data/history.json` | історія цін по кожному посиланню (пише робот) |

## Як замінити деталь

1. На сайті біля деталі натисніть «Замінити» — відкриється GitHub issue «Заміна деталі» з уже заповненими полями (збірка, деталь, назва, посилання).
2. Перевірте поля й створіть issue.
3. Робот (`.github/workflows/replace.yml`) перевірить дані, запише заміну в `data/overrides.json`, отримає ціну, напише коментар з результатом і закриє issue.

Повернути оригінальну деталь: у полі «Посилання» напишіть `reset` (або створіть issue із заголовком `Скинути: user cpu`).

Можна писати й простим текстом — issue із заголовком `Заміна: ...` і тілом:

```
build: alt
part: gpu
name: MSI GeForce RTX 5070 Ti 16G VENTUS 3X OC
url: https://geizhals.de/msi-geforce-rtx-5070-ti-16g-ventus-3x-oc-plus-a3382170.html
```

Правила:

- `build` — `user` або `alt`; `part` — `cpu`, `cooler`, `mb`, `ram`, `ssd`, `gpu`, `case`, `psu`;
- `url` — посилання `http(s)://` до 500 символів (без IP-адрес і localhost) або `reset`;
- `hotline` — порожньо або `https://hotline.ua/...`; `name` — до 200 символів.
- **Заміни застосовуються лише для власника/співавторів репо.** На чужі issue робот відповість, що змінювати збірку може лише власник.
- Щоб форма автоматично ставила мітку, у репо має існувати label **`заміна`** (без неї працює розпізнавання за заголовком `Заміна:` / `Скинути:`).

## Запуск локально

Потрібен Node.js 22+ (залежностей немає).

```bash
node scripts/update.mjs                   # оновити всі ціни
node scripts/update.mjs --only-overrides  # перевірити лише заміни

# застосувати заміну без GitHub (DATA_DIR — щоб не чіпати справжні data/)
ISSUE_BODY=$'build: user\npart: gpu\nname: Test\nurl: https://example.com/x' \
  DATA_DIR=/tmp/data-copy node scripts/apply-issue.mjs

# переглянути сайт
npx serve .        # або: python -m http.server
```

Перевірено 2026-11-15 звичайними запитами (без обходу захисту).

| Джерело | З домашнього ПК | З GitHub Actions |
|---|---|---|

| Mindfactory, Alternate, ARLT, Future-X, Jacob, DiTech.at, office-partner.de, Caseking | ✅ | ✅ |
| MediaMarkt, Saturn, e-tec.at | ✅ | ⛔ |
| Amazon.de/.com (ціну ботам не показує), Cyberport, Galaxus, alza.de, Proshop, notebooksbilliger, Otto, Kaufland, Newegg, B&H, PCPartPicker | ⛔ | ⛔ |
| Red Tech (посилання з таблиці) | товар знято з продажу (404) | — |

Тому ціни Geizhals оновлює **завдання Планувальника Windows** на домашньому ПК (`scripts/local-update.cmd`, кожні 2 год), а GitHub Actions — посилання магазинів, що не блокують сервери, і заміни деталей.

## Обмеження

- **Amazon, Cyberport, Galaxus і PCPartPicker блокують автоматичні запити** (капча / Cloudflare / HTTP 403). Для них сайт показує помилку й посилання; ціну таких деталей видно через Geizhals.
- Ми **не обходимо захист** магазинів: лише звичайні HTTP-запити до публічних сторінок, не частіше ніж раз на 2 години, з паузою між запитами.
- Ціни орієнтовні: магазини можуть змінювати їх частіше, ніж працює робот; знижки за кошиком, доставка й наявність не враховуються.
- Розклад GitHub Actions не точний — запуск може запізнитися на кілька хвилин або більше.
